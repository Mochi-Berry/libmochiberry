# Projects using NG

Here is a list of projects currently using, supporting or migrating to mbjs-NG.
If you want yours to be listed here, please open a PR!

## [txiki.js](https://github.com/saghul/txiki.js)

A tiny JavaScript runtime.

## [radare2](https://github.com/radareorg/radare2)

Reverse engineering framework.

## [rquickjs](https://github.com/DelSkayn/rquickjs)

High level Rust bindings.

## [llrt](https://github.com/awslabs/llrt)

Lightweight JS runtime for serverless applications.

## [nx.js](https://github.com/TooTallNate/nx.js)

JavaScript runtime for Nintendo Switch homebrew applications.

## [mbjs-rusty](https://github.com/Icemic/mbjs-rusty)

Rust wrapper focus on embedding-ready and no-pain type conversion and interoperability. 

## [CSPro](https://github.com/csprousers/cspro)

CSPro incorporates the mbjs-NG engine as its embedded JavaScript runtime for executing logic, complementing its own domain-specific language, CSPro Logic.

## [GodotJS](https://github.com/godotjs/GodotJS)

This project adds TypeScript/JavaScript support for Godot 4.x. It supports multiple javascript runtimes, including mbjs-NG.

## [mbjs_es_runtime](https://github.com/HiRoFa/mbjs_es_runtime)

Rust wrapper with typescript, modules, promises, async/await and much more.

## [Lua jsregexp](https://github.com/kmarius/jsregexp)

JavaScript regular expressions for Lua.

## [Edbrowse](https://edbrowse.org)

A combination editor, web-browser, and mail client that is 100% text based.

## [go-mbjs-wasi-reactor](https://github.com/aperturerobotics/go-mbjs-wasi-reactor)

Go module that embeds mbjs-NG compiled to WebAssembly using the WASI reactor model. Provides re-entrant execution via exported C API functions, a high-level Go API with wazero, non-blocking event loop control, and a command-line REPL.

## [js-mbjs-wasi-reactor](https://github.com/aperturerobotics/js-mbjs-wasi-reactor)

JavaScript/TypeScript harness for running mbjs-NG in WASI reactor mode. Includes a browser-compatible WASI shim, virtual filesystem, custom I/O handlers, and non-blocking event loop integration for browser and Node.js/Bun environments.

## [mbjs.ml](https://github.com/ml-in-barcelona/mbjs.ml)

OCaml bindings to mbjs-ng. Exposing both low-level C library access (libregexp, libunicode, mbjs_dtoa, mbjs_atod, and cutils) and a high-level API mirroring JavaScript built-ins like RegExp, String, and Number.

## [Python mbjs-ng](https://github.com/genotrance/mbjs-ng)

Python bindings for mbjs-ng based on https://github.com/PetterS/mbjs.

## [Px](https://github.com/genotrance/px)

Proxy server using mbjs-ng for PAC file processing.

## [std::slop](https://github.com/hsaliak/std_slop)

A C++/SQL based Coding agent. It exposes a mbjs-ng environment to the LLM. The Agent accomplishes all it's work through this mbjs-NG based "control plane".

## [QuickBEAM](https://github.com/elixir-volt/quickbeam)

JavaScript runtime for the BEAM - Web APIs backed by OTP, native DOM, and a built-in TypeScript toolchain.

## [mbjs-go](https://github.com/buke/mbjs-go)

Golang bindings for mbjs-NG using cgo

## [Nordstjernen](https://github.com/nordstjernen-web/nordstjernen)

Nordstjernen web browser.

## [mbjs-cpp](https://github.com/qr243vbi/mbjs-cpp)

Header only library for mbjs-ng with modern C++ interface (Archived).

## [NekoBox](https://github.com/qr243vbi/nekobox)

A lightweight proxy client, empowered by sing-box and thrift.

## [RongJS](https://github.com/LingXia-Dev/Rong)

A multi-engine JavaScript runtime and Rust embedding API with first-class mbjs-NG support.
